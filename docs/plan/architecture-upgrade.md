# 建物とダンジョンの分割改修

2026-10-02。開発者依頼：屋根なしの家とダンジョンをなくし、完成度・階層・迫力・仕掛けを上げる。分割して作り、後で結合する。

## C1 家と室内

担当ファイル：interiors.js、townbuildings.js。
外観は既存の町別屋根を保ち玄関を仕上げる。室内は描かれていなかった壁を直し、閉じた天井・梁・灯りを作る。家具の検索キー、入口、部屋座標、既存セーブを維持。入室時だけカメラを調整し、退室時に戻す。

## C2 灯台ダンジョン

担当ファイル：lighthouses.js。
まず任意の灯台内部8区間を対象に、高い閉天井・重厚な入口と骨組み・仕掛けの状態表示を作る。追加階層は実際の床と階段でつなぎ、名前だけの階数増加にはしない。既存の点火、本編条件、報酬、扉、クリアキー、帰還先を保つ。
本編の遺跡・祠・宮などは別の区間として後続で扱う。この作業で全ダンジョンを完成したとは報告しない。

## C3 結合と確認

独立したコードレビュー後、共通版番号で結合。短いPC横画面確認で入退室、カメラ、階段、閉天井、屋根/壁の衝突、仕掛け、帰還、旧クリア状態を確かめる。各地域の可視ブロック数を24000上限と比較する。保護ブロックを使い、プレイヤー配置セーブへ建物を混ぜない。
灯台入口/ゴールを包むdungeonfx.jsの演出・メダル記録を外さない。

## Claudeとの境界

Claudeは町・道・港の仕上げを担当。Codexの3ファイルと共通ファイルを同時に全文変更しない。Claudeの入口名前札は別の差分として維持する。最新mainからPRへ必要な差分だけ入れ、版番号は結合時に照合。main直接アップロードは禁止。

## 確認の扱い

PCの変更範囲の描画検査をiPhone実機確認とは扱わない。取り消された実機・全章通しの予定を復活させない。作業・保存・GitHub送信・統合・公開を分けて報告する。
