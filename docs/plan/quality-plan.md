## 0. なぜ今か

- 量はもう十分。ここからは「重くない・迷わない・壊れない・お金が崩れない」が品質を決める。

## 3. 計測の道具（Claude が作る）
- **重さ**：デバッグ表示（`#debug`）に、fps・描いているブロック数・人の数・描画の呼び出し数を出す。iPhone では画面の左上に小さく。
- **お金**：収入源ごとの試算（宿・装備の値段と、調べもの・カジノ・道場・朝市・依頼・戦闘の1時間あたり）を docs/reports に表で出す。
- **回帰テスト**：これまで scratchpad で使ってきた検査（町のくらし・家の中・灯台・新しい町・会話・連携・住人・天気・称号・レシピ）を `tests/` に置き、`npm run test` で誰でも実行できるようにする。

## 4. PR ごとの品質チェック（全員）
1. `npm run check` と `npm run test` が通る
2. 新しいセーブの値は、読みこみ時に初期値を入れる（旧セーブで壊れない）
3. 844×390 の画面写真を1枚（見た目が変わるとき）
4. 「保存済み／公開済み／未確認」を分けて書く
5. 設定・物語に関わるものは docs に採用の記録を残す
6. 1件1PR。同じファイルを別の担当が同時に触らない
