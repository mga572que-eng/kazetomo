# Gemini 作業指示 03：仲間モンスターの専用化（「お荷物」→「育てたい」）

作業ブランチ：`work/monster-companions`
添付するファイル：AGENTS.md, AI_HANDOFF.md, ROADMAP.md, GEMINI.md, index.html, game.js, data.js, art_mon.js, jobs.js, sw.js

## 現状
- 仲間モンスターは `G.mons`（uid, id=種族, lv, iv, bond, extra）にいる。種族データは `DATA.species`、技は `DATA.skills`。
- 図鑑・技の継承（ツムギ）はある。ただし人間より弱く、個性もないため、使う理由がない。

## 作るもの（新ファイル `monplus.js`。読込順と sw.js の CORE への追加以外は既存ファイルを変えない）
1. 専用装備：種族ごとに「専用の武器と防具」を1つずつ。強化は3段階で、素材を使う。人間は装備できない。保存は新しいキー `G.monEq`（`{uid:{w,a}}`）に入れる。
2. 固有技：種族ごとに3つ。なつき度（bond）とレベルの節目で覚え、人間の職業スキルと役割がかぶらないようにする（例：盾役、状態異常、連携の起点）。
3. 進化：主要な種族は1回進化する。条件はレベル、なつき度、専用装備の段階。進化後は名前・見た目の色・技が変わる。`m.evo` に保存し、ない場合は未進化として扱う。
4. 話し言葉：種族ごとに口調と口ぐせを決める（仲間会話 01 で使うため `K.monVoice[種族]` として公開する）。
5. 連携：人間キャラとの専用連携技を4つ以上。`DATA.combos` と同じ形式で追加する。

## 守ること
- 既存の uid、種族ID、セーブ形式を変えない。新しい値はすべて「なければ初期値」で読む。
- 計算への反映は HOOK.calc（ステータス）と HOOK.gain（経験値）を使う。calc 本体は書き換えない。
- 強さの目安：育てたモンスター1体が、同じレベルの人間とほぼ同じ価値を持つこと。上回らないこと。

npm run check が PASS すること。既存セーブのモンスターが壊れないこと。新規データで1体を進化まで育てる手順を docs/design/monsters.md に書くこと（デバッグ手順付き）。
