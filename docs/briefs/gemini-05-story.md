# Gemini 作業指示 05：物語の改稿案（コードは書かない）

出力：`docs/design/story.md`
添付するファイル：ROADMAP.md, game.js（talk〜で始まる関数とイベント）, ch4.js, quests.js, data.js, docs/lore/foreshadow.md（あれば）

## 目的
陪審で6点止まりの「物語」を8点以上にする。分かりやすさ、人間の深み、登場人物への愛着が課題。

## ほしいもの
1. 人物相関図（文字の図でよい）。家族、恩、借り、嘘、嫉妬を含める。
2. 章ごとの改稿方針：今の筋を壊さずに、各章で「誰が何を失い、何を選ぶか」を1つずつ足す。
3. 主要な場面（各章3つ）のセリフ改稿案。既存の `who(id, 表情, 'セリフ')` 形式と、ひらがな多めの文体で書く。
4. 悪役やかげものの側の理由（単純な悪にしない）。
5. 伏線の一覧と回収場所の表（02 の訳あり家と食い違わないようにする）。

## 守ること
既存の進行フラグとイベントの順番を変えない。追加のイベントは「どのフラグの後に入れるか」を書く。子どもが遊べる表現の範囲に収める。
