## 目的
1. 仲間会話：フィールド、町、ダンジョンでメニューの「はなす」から、隊列にいる仲間（人間と仲間モンスター）と会話できるようにする。
2. モブ：各町（region 0〜3）に、名前と生活を持つ住人を、1つの町あたり12人以上追加する。

## 作るもの
- 新ファイル `talk.js`（仲間会話）と `mobs.js`（住人）を作る。index.html では `unstuck.js` の後に読み込み、sw.js の CORE にも足す。
- 既存ファイルの変更は、上の2行（読込とキャッシュ）だけにする。既存の関数を書き換えたり、別の雛形に置き換えたりしない。
- 拡張は必ず `window.KZ`（K）と `K.HOOK`（menu / talks / frame / load など）を通して行う。

## 仲間会話の仕様
- 条件で選ぶ：地域、章とフラグ、場所の種類（町・灯台・祠・野外・海中）、時間帯（`World.skyInfo(G.tod).night`）、HPの低さ、直前の戦闘結果、進行中のクエスト、話している仲間。
- 使い回し禁止：一度出たセリフはセーブ内の既読リストで管理し、同じ条件では次の未読セリフを出す。全部読んだら、汎用ではなく「その場の一言」（短い反応セリフ）を出す。
- 既読リストは新しいキー `G.talkSeen`（オブジェクト）に入れる。古いセーブで無い場合は HOOK.load で `{}` に初期化する。セーブキーは変更しない。
- 中身：プレイヤーと同じ感情や感想、次に行く場所のヒント、人生のあるある、そのキャラの生い立ちや口ぐせ、進行中の物語やサブクエストへの反応、仲間同士のかけあい（2〜4行）。
- 量：キャラ1人あたり40本以上。仲間モンスターも種ごとに口調を決めて、それぞれ15本以上。
- 文体：既存の `who(id, 表情, 'セリフ')` 形式、分かち書き風のひらがな多め、`{name}` で主人公の名前を入れる。大人が読んでも浅くない内容にする。

## モブの仕様
- 1人ごとに：名前、職業、家族や近所との関係、口ぐせ、時間帯で変わる2〜3本のセリフ、うわさ（他の住人や伏線につながるもの）を持たせる。
- 町の個性に合わせる：島＝漁村、大陸＝交易の町、空＝雲の町、海中＝シオミの町。
- 「訳あり」の家の伏線になる、うわさのセリフを各町に3本以上入れる（回収は後の部署が担当。うわさの一覧は文書に残す）。
- 配置：家や道の上。当たり判定にめり込まない座標にする（`K.blocked(x,z,y)` で確認）。

## 守ること

- 既存NPCのIDと会話の流れを変えない。新しいIDには `mob_` や `pt_` の接頭辞を付ける。
- 実在の作品のセリフや固有名詞は使わない。
