# Gemini 作業指示 06：全コード監査（コードは書かない、修正案は diff で）

出力：`docs/reports/qa-audit.md`
添付するファイル：リポジトリの全 .js、index.html、sw.js、manifest.webmanifest、AGENTS.md、AI_HANDOFF.md

## 見てほしいこと（物理・QA部署＋UI部署）
1. 不具合：例外になりうる箇所、未定義のまま参照している値、古いセーブで落ちる箇所（HOOK.load の移行漏れ）。
2. 物理：はさまり、すり抜け、落下ダメージがない高さ、水中・空中の不自然な挙動。
3. iPhone横画面：✕やボタンに指が届かない、セーフエリアや比率設定で画面から切れるUI。
4. 性能：毎フレームのメモリ確保、重いループ。

## 出し方
1件ごとに「重大度（高・中・低）／ファイル:行／再現手順／原因／修正案（unified diff）」を書く。推測は「推測」と明記する。高の件数を最初に要約する。
