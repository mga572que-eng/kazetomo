# Gemini 作業指示 02：酒場・訳あり家・隠しアイテム（町部署＋伏線部署）

作業ブランチ：`work/town-foreshadow`
添付するファイル：AGENTS.md, AI_HANDOFF.md, ROADMAP.md, GEMINI.md, index.html, game.js, data.js, quests.js, ux.js, deco.js, sw.js

## 目的
町を「通過点」から「歩き回って話を集める場所」にする。

## 作るもの（新ファイル `town.js` だけ。index.html の unstuck.js の後で読み込み、sw.js の CORE に追加する）
1. 酒場（大陸・空・海中の各町に1軒）
   - マスターに話すと、次の目的地や隠し場所のヒントを、章とフラグに応じて出す（有料と無料の両方）。
   - 賭け事のミニゲームを1つ作る（例：カードの数の大小当て）。1回の上限額を決め、ゴールドの使い道にする。景品は限定アイテム。
   - 常連客を3人以上置き、うわさを話させる。
2. 訳あり家（各町に1〜2軒）
   - 表向きの様子 → 住人3人以上のうわさ → 本人の告白、の3段階で理由が分かるようにする。
   - 進行は `G.flags` に新しいキー（`tw_` 接頭辞）で保存する。古いセーブでは未定義を「未発見」として扱う。
   - 回収する章とイベントを docs/lore/foreshadow.md に一覧で書く（実装は後で行う）。
3. 隠しアイテム（各町に5か所以上）
   - 屋根の上、樽の中、桟橋の下など、町の個性に合わせた場所にする。取得済みは `G.flags.tw_hid` の配列で管理する。

## 守ること
- 既存NPCのID・会話・店を変えない。NPCは `K.NPCS.push`（quests.js の addNpc と同じ形）で足す。
- 町の個性：島＝漁村の素朴さ、大陸＝交易と格差、空＝閉じた共同体、海中＝秘密と信仰。
- 人間の醜さ（見栄、嫉妬、借金、嘘）も描く。ただし子どもが遊べる表現の範囲に収める。
