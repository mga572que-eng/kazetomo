# 敵の見た目と呼び方（2026-10-03 開発者の決定）

## 決定
- 敵は「かげ」（闇にのまれて紺紫になった いきもの）をやめ、**本来の色と個性で出す**。名前の「かげ○○」もやめる。
- 絵の方向は **A案：太い線のアニメ調（デフォルメ）**。2Dはもともと太い輪郭（art_mon.js）、3Dは輪郭線を足した（world.js の m.outline）。
- 敵の総称は **「まもの」**（旧「かげもの」）。

## 物語との関係（変えていないこと）
- 闇が まものを あらぶらせている、灯で しずめる・なかまになる、という流れは そのまま。
- ボス（番人）は「やみが はれて…」と言う（旧「かげが はれて」）。
- 「かげの くも」など、闇そのものや ふつうの影（木のかげ・くものかげ）は「かげ」のまま。
- 技名の「かげうち」「かげぬい」もそのまま。

## 実装（PR）
- #49 本来の色・名前／#50 3Dの輪郭線／この PR で 台詞の「かげもの」→「まもの」（32か所）と意味が変わる8か所。
