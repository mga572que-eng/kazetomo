# 灯台の建物と4階

8基の任意ダンジョンを、天井のある建物として組み直す。3つの既存の間と仕掛けはそのまま。かけらの扉の先に1mずつ上がる階段と4階のひざらを追加する。

- 一・二の間の天井は基準床から13m、三・四の間は16m。最高の台の上にも第三人称カメラの余白を残す。
- 外壁を天井まで伸ばし、高窓、ひさし、外側の太い柱で外観を整える。通路や仕掛けの座標に柱を置かない。
- 旧 `lhDun` / `lhDunExit`、8基のキー、点火条件、報酬、3つの仕掛けを維持。建物は保護ブロックで、プレイヤーの設置ブロックセーブには入らない。
- 同じ地域では1棟だけ常駐。リセット時は所有する建物を入れ替え、天井を重複させない。
- 間の仕切りと天井が高くなる切り替え面も閉じる。最後の扉は元の高さを保ち、頭上と横の壁を天井まで伸ばす。高いかけらの台から扉を飛び越えられない構造にする。
- ダンジョン内の案内は階と仕掛け・かけらの進捗に切り替わる。外の目的地への矢印を出さず、退出すると元の案内へ戻る。保存された追跡対象は変更しない。

検査：`node tests/architecture-dungeons.mjs` は8基の屋根、4階への階段、3つの扉、リセット、仕掛けを飛ばした時の報酬拒否、報酬の一度だけの付与を確認。`--render` では独立した第1章データで入口・最高のかけら台・4階を描画し、カメラが天井の下にあることと地域のブロック数を確認する。この3枚は位置を指定した建物の視界検査で、仕掛けを順に攻略した画像ではない。最後の階段は普通のW入力のまま物理を最大120フレーム進め、4階に着いたら入力を止めて到達を検査する（ソフトウェアGPU描画だけをその間休止）。iPhone・全章通しの予定は追加しない。

2026-10-02の結果：8基の構造・進行条件検査成功。第1章の地域全体は最大12,753ブロックで24,000上限内。入口、最高のかけら台、4階でカメラは天井の下。最後の階段は29フレームの通常入力で4階に到達し、`stuckAt` は false。入力を止めた後も4階の目標範囲内に留まった。全章・実機・端末別の性能測定はしていない。
