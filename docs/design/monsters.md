# ともしびアイランド 仲間モンスター専用化設計書

本書は「ともしびアイランド」における仲間モンスターのゲーム内価値を再定義し、「ストーリー中盤以降のお荷物」から「人間キャラクターと明確に差別化された、育てたく・使い分けたくなる相棒」へ昇華させるための設計仕様書である。

---

## 1. 仲間モンスターの基本方針と役割定義（ロール）

人間キャラクターが職業ツリーや多種の装備・固定ストーリーを持つ一方、仲間モンスターは以下の**4大特権**によって人間を上回る独自性を発揮する。

1. **タイプ一致による属性倍率（1.5倍）**: 人間は属性武器やスキルに依存するが、モンスターは素体から属性を持ち、同属性スキルの威力が常時高水準。
2. **アーキタイプ固有の行動モーションと特性**:
   - `fluff` (綿毛): 癒し・支援型。全体リジェネや状態異常解除に長ける。
   - `quad` (四足): 俊足物理・壁役。高いHPと鈍足付与・確定行動。
   - `golem` (岩石/巨人): 鉄壁タンク。圧倒的装甲と全体土属性粉砕。
   - `blob` (軟体): 魔法妨害・持久型。水流による足止めとMP効率。
   - `bird` (鳥/翼): 超高速先制型。開幕の速度支配・回避攪乱。
   - `sprite` (精霊): 属性魔法アタッカー。高威力光/炎打線。
   - `plant` (植物): 毒・継続ダメージ支配型。持続毒でボスの体力を削る。
   - `fish` (魚類): 潮流遊泳・バランス型。水・光魔法と全体大波。
3. **専用装備（首輪・装飾具）**: 人間用の武器・防具とは異なり、割合HP回復や属性威力UP、状態異常無効など強力なパッシブを持つ専用具を1枠装備可能。
4. **人間 × モンスター 絆連携技（コンボ）**: パーティに対象アーキタイプとなつき度50以上のモンスターがいることで、人間キャラと共同で放つ必殺連携がアンロックされる。

## 2. なつき度（Bond）システムと覚醒

### 2.1 なつき度の上昇と恩恵
- **上昇手段**:
  - 戦闘に参加して勝利: +1（倒れずに生存時）
  - たき火でおやつ（料理）を与える: 木の実 +2、実のパン +4、焼き木の実 +5、きのこ汁 +8、星のシチュー +12
  - 専用装備「きずなのリボン」装備時は上昇値が2倍
- **なつき度段階ボーナス**:
  - `Bond 20`: 会話バリエーションが変化（打ち解ける）
  - `Bond 30`: **ふんばり**（致死ダメージ時、なつき度に応じた確率でHP1で耐える）
  - `Bond 50`: **全パラメータ +5%**、人間との「絆連携技」が解禁
  - `Bond 80`: **会心率 +5%**、仲間モンスター専用の愛着セリフが解放
  - `Bond 100`: **全パラメータさらに +5%**（計+10%）、「**きずな覚醒**」が可能になる

### 2.2 きずな覚醒（Awakening）
- なつき度100に達したモンスターは、ステータス画面で「きずな覚醒」を実行可能。
- **覚醒効果**:
  - モンスター名に「★覚醒」バッジが付与
  - 最大HP +15%、最大MP +15%、攻撃力 +10%、防御力 +10%
  - 常時パッシブ: 毎ターンHP 3%自動回復
