# 町の くらし（生活部署）設計と品質基準

記録：Claude ／ 2026-10-02 ／ 開発者の依頼：「町の人は突っ立っているのではなく生活している。人の数で町の規模、栄え度・物価、城・宮殿・世界会議・勇者の町・カジノ大国、家の中の個性、夜の窓と街灯、郵便屋・バー・食事処。総括プロデューサーを立ててクオリティを上げる」

## 1. 体制
| 役 | 受けもち | 判定 |
|---|---|---|
| **総括プロデューサー** | 下の「品質の5条件」で毎回の PR を点検し、合格しないものは出さない。本編の設定（栄え度・町の歴史）とのずれを止める | PR ごとに ○／× を記録 |
| 生活部署 | 1日の予定（仕事・学校・買いもの・食事・帰宅）、役割（郵便屋・見回り・先生・行商人） | 時刻を変えて、居場所と動きが変わるか |
| 町づくり部署 | 人数＝町の規模、街灯・物干し・家畜・屋台・学び舎、建物の形 | 町ごとに「らしさ」が見分けられるか |
| 経済部署 | 栄え度と物価（宿・道具屋の買値） | 本編の設定と矛盾しないか、収支が壊れないか |
| 動き部署 | 関節（腰・肩）で 腕と足を ふる。歩く・はたらく・すわる | 歩幅と速さが合っているか、すべって見えないか |
| 室内部署（次） | 家の中：台所・かまど・洗濯おけ・寝床・家畜小屋 | 家ごとに住む人の仕事が分かるか |

### 品質の5条件（総括プロデューサーの基準）
1. **動機**：その人が「なぜ そこに いるか」が、時刻と役割で説明できる。
2. **規模感**：人数・屋台・街灯の数が、町の栄え度と一致する。
3. **昼と夜**：夜は家に入り、窓と街灯が光る。物干しは夕方に取りこむ。
4. **設定との一致**：シオミ＝火事から復興中（物不足で高い）など、本編の事実に合わせる。新しい過去・家族は足さない。
5. **重さ**：iPhone で重くならない（見えない所は歩かせない・同じ形はまとめて描く）。

## 4. 段階
- **第1段（このPR）**：上の予定で住人が動く。関節つきの歩き・作業・すわり。郵便屋・見回り・先生・行商人など町ごとに 3〜14人を追加（ミナトがいちばん多い）。街灯（夜に点灯）・物干し（夕方に取りこむ）・にわとり／ヤギ・屋台・学び舎。町に入ると「人口・にぎわい・物価」を表示。宿と道具屋の買値に物価をかける（売値は変えない）。
- **第2段（実装 2026-10-02）**：家の中に入れる（12軒：ソラの家・ゲンの工房・かざみ亭・町長ナミ・漁師リョウ・研究所・ソヨギ・ウシオ・ハッサン・ウララ・風車小屋・ハヤテの家）。寝床・タンス・本棚・台所・かまど・樽・ツボ・洗濯おけ・物干し・じゅうたん・植木ばち。仕事で中身が変わる（工房＝金床と武器の木箱、漁師＝網と干物、料理＝台所2つと粉ぶくろ、学者・占い＝本棚と水晶、風車＝粉ぶくろと機織り、長老と家庭＝ねこ）。
  - しらべる：タンス（ときどき服・軽い防具）、樽・ツボ・木箱・ふくろ・台所・かまど・洗濯おけ・ベッド（道具・お金）、本棚（本の一節）、工房の木箱（武器）。町の外にも樽・ツボ・木箱を置いた。1か所1回。武器と防具は店で売っている品のうち地方ごとの上限価格（島500G〜海8,000G）以内（ゲンの工房で打つ品は出ない）で、そうびの袋へ。
  - 花：町の花だんと家の植木ばちに水をやると45秒でさき、つみとれる（お花・薬草）。何度でもできる。
  - セーブに足したのは G.searched・G.garden だけ。家の中の部屋は地方ごとに1つを使いまわす（ブロック数をふやさない）。
- **第3段（実装 2026-10-02・開発者が設計書の案で承認）**：霧の大陸に3つの町（newtowns.js）。本編の進行は変えない寄り道。
  - **王都 ルミナリア**（北の平原）：城（外壁・4つの塔・天守）、中庭の王座と世界会議の円卓。王さま・大臣・4か国の代表・門番。宿・道具・武器・防具。人口800・とてもにぎやか・物価1.15。世界会議の話題は、本編で起きたことだけ（章のフラグで変わる）。
  - **黄金の都 ラッキーナ**（東の砂漠）：屋根なしのカジノ（ダイス・スロット・ハイ＆ロー。期待値はどれも0.95前後）と劇場（30Gで HP・MP全回復）。負けこんだ男・見栄っぱりの大金持ちなど人間くささ。人口400・物価1.3。
  - **はじまりの町 ブレイブ**（西の平原）：「はじまりの勇者」の像、道場（けいこ試合3連戦）。勇者に憧れる若者の町。人口150・物価1.0。
  - 町に入ると地図にワープが増える（`G.flags.nt_royal / nt_lucky / nt_brave`）。町の中には魔物を入れない。
  - 描くブロックの上限を地方ごと9000→14000に（霧の大陸は 約11,200）。**iPhone での重さは未確認**。
  - 案に入れていた「海の航路の島」は、島の地形を新しく作る必要があるため見送り、勇者の町は大陸の西に置いた。
- **第4段**：町ごとの建物の形（シオミの焼け跡と新築、ミナトの倉庫街と石だたみ、サラムの日干しれんが）。

## 6. 天気（2026-10-02 実装：weather.js）
- 地方ごとに 4分（ゲーム内 半日）ごとに変わる。割合のめやす：島 雨20%・霧8%／大陸 雨15%・霧6%（砂漠の上は雨なし）／空 雨6%・霧22%／海の底 なし。セーブには何も足さない（遊んだ時間から決まる）。
- 雨：画面に雨すじ・少し暗く。町の人は、子どもとお年寄りは家へ、ほかは半分が宿・酒場の軒下で雨宿り、残りは傘をさして歩く。店番・見回り・先生はそのまま。花だんは雨で水やりずみになる。
- 霧：画面が白くかすむ。
- 雨の日の台詞は `K.weather.LINES[町の key]` に入れると、住人に話しかけたとき雨なら半分くらいそれを言う（台詞は Gemini G-F で用意）。
- 設定 `HOOK.OPT.weather === false` で止まる。
- 雨の日の台詞（2026-10-02）：Gemini G-F の 9町×6つを照合して採用。町に無いものを言う4つを直した（王都の「大聖堂」→お城、ラッキーナの「ネオン」→虹色のかざり、「カジノの中なら ぬれない」→屋根のないカジノ、ブレイブの「道場の床」→道場の庭）。
