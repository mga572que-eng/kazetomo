# 起動時・回転時の 画面の 不具合（原因と 再発防止）

記録：Claude ／ 2026-10-05 ／ 開発者の 報告「起動時に 言葉や ボタンが 上下に ゆれる・スマホを 横に すると 半分が 真っ暗・画面が 圧縮される」

## 原因
1. **半分が 真っ暗・圧縮**（再現ずみ）：iPhoneの ホーム画面アプリで 縦向きの とき、下の 黒い帯 対策で キャンバスに 縦の 大きさ（390×844px）を 書きこんでいた。横に すると その 条件に あたらず、px が 消されずに のこった → 横画面の 半分しか うめず、中身も 縦の 比率で ひずんだ（settings.js applyRatio）。
2. **上下の ゆれ（測りなおしの くりかえし）**：大きさを 測るたびに「いったん 全部 もどす → 置きなおす」を していて、resize と visualViewport の resize が 何度も 来るたびに 位置が 変わりうる。回転の 途中は innerWidth と visualViewport が くいちがう ことも ある。キャンバスの width を 同じ 値で 代入しても 一瞬 黒く なる。
3. **起動時の ゆれ（字体）**：日本語の Webフォントを display=swap で 読んでいた。日本語フォントは 文字の 範囲ごとに 何十回にも 分けて とどくので、とどくたびに 文字の 幅と 高さが かわり、文字と ボタンが ずれた。

## 直し方
- settings.js：「測る → 前と 同じなら 何もしない」。向きの くいちがいは innerWidth/innerHeight に そろえる。キャンバスの px は 必要な とき だけ 付け、いらない ときは 必ず 消す。回転などの あとは すぐ・次の 描画・0.15・0.4・0.8秒で 測りなおす（同じなら 何もしない）。画面に もどった ときも 測る。
- world.js：キャンバスの 大きさは 実際に 見えている 大きさ（clientWidth/Height）から。同じ 大きさなら 代入しない。画面座標への 変換も 同じ 値で。
- index.html：Webフォントを display=optional に（間に あわなければ その回は システムの 字体の まま、入れかわらない）。

## 再発防止
- check.mjs：Webフォントが display=swap なら 失敗（GitHub の Game checks で 止まる）。
- tests/viewport.mjs（`npm run test:viewport`）：iPhone ホーム画面アプリの 縦→横・横→縦→横で 画面いっぱい・ひずみなし・測りなおしで 値が かわらない。直す前の main では「横に しても キャンバスが 390×844 の まま」で 失敗することを 確認。
- 画面の 大きさを かえる 処理は settings.js の applyRatio に まとめる。ほかの ファイルで キャンバスや body に px を 書かない。
- 実機未確認（PCの 再現のみ）。
