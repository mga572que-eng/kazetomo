# 職業の支援能力と新しい職業（2026-10-01 実装）

パーティの**だれか1人**がその職業なら効く（重ならない。同じ職業が2人いても効果は同じ）。

| 職業 | 支援能力 | 実装の場所 |
|---|---|---|
| 見習い灯守 | 地図に、まだ開けていない宝箱が出る | jobfield.js（mapMarks） |
| 戦士 | 岩を少ない回数でこわせる（3→2、いわ系モンスターと合わせると1） | game.js の岩の処理 |
| 魔法使い | 夜の灯りが1.5倍広い | game.js の灯り |
| 僧侶 | 歩いた距離4mごとに、全員HP2%回復 | jobfield.js |
| 盗賊 | 戦闘で「ぬすむ」（1体1回・1戦闘3回まで）、戦後にときどき戦利品 | jobfield.js・jobs.js |
| 武闘家 | がんばりの回復が速い | jobfield.js |
| 吟遊詩人 | 敵に追いかけられる距離が 12m→7m | game.js の敵の追跡 |
| 勇灯 | 4mごとにHP1%回復、戦いの稼ぎ+10% | jobfield.js |
| **商人（新）** | 装備の売値が4割→5割、戦いの稼ぎ+25% | balance.js・jobfield.js |
| **狩人（新）** | フィールドの採取（薪・石・葉・キノコ・木の実・砂・雲わた）で1つ多く手に入る | jobfield.js |

## 新しい職業
- **商人**：小判を投げる技（コバン投げ・コバンの雨・オオバン投げ）。MP の代わりにゴールドを使う。値段は地域が進むほど高い（基本×(1+地域番号)）。お金の使い道にもなる。「おまかせ」ではお金の技を使わない。
- **狩人**：ねらい撃ち・コノハ・ドクミ・矢の雨・シガラミ打ち・ゼカザネ撃ち。すばやさと会心が高い。
