# 面白さ部署（遊びの設計）— 全要素の点検と「最高級」への改修案

記録：Claude ／ 2026-10-02 ／ 基準：main 452c8eb ／ 開発者の依頼：「面白みが欠ける要素を点検。カジノは筆頭。宝箱のわくわく、ボス戦の怖さ・演出、ダンジョンも全部見直す」

## 部署の役目
- 「動くか」ではなく「**やりたくなるか・もう一回やりたいか**」を見る。品質部署（docs/plan/quality-plan.md）と並ぶ17番目の部署。
- 点検のものさし（5つ）：
  1. **期待**：始まる前に「何が起きるか」わくわくするか（溜め・予告・光・音）
  2. **手ごたえ**：自分の判断や腕で結果が変わるか（ただのボタン押しになっていないか）
  3. **ごほうび**：もらえる物が「その場所でしか手に入らない」特別さを持つか（ただのお金・回復道具になっていないか）
  4. **変化**：2回目・10回目も同じにならないか（ランダム・段階・記録更新）
  5. **余韻**：終わったあとに見せたくなる・語りたくなる瞬間があるか（演出・記録・称号）

## 進め方
- ①カジノ→②宝箱→③ボス→④ダンジョン の順に1件1PR。各PRに「5つのものさし」の前後比較を書く。
- お金の釣り合い（品質プランの部署1）を崩さない：カジノは**コイン**で遊び、コイン→お金には戻せない（景品だけ）。宝箱・ボスの演出は中身を変えない。
- そのあと、品質プランの段階A〜D（計測の道具・回帰テストなど）を進める。
