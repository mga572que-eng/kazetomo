# ともしび（移動ゲージの 作りなおし）2026-10-06

## なぜ
- 空の島の 風の羽（3まい とらないと 先へ 進めない）が、滑空の 小回りが きかず 何回やっても とれなかった。
- 「がんばりゲージ＋滑空」は 他の作品に 近すぎて、この島らしさが なかった。

## どう変えたか（このゲームの 軸＝灯 に そろえる）
1. **ともしびゲージ**（旧 がんばり）：走る・登る・ふわりで へる。**灯りの そば**（町・たき火・ともした 灯の樹・海の灯台・ランタン）では 一気に 満ちる（毎秒70）。ほかは ゆっくり（止まって14・歩いて7）。→「次の 灯りまで もたせる」遊びに。
2. **灯の実**：高い崖・山の 中腹・空の島の 上昇気流の 上に うかぶ 光の 玉。ふれると ともしびが 半分 もどる。90秒で また なる。登りの とちゅうの 休み場。
3. **風の道**（空の島）：島どうしと 風の羽を つなぐ 光の 流れ。ふれると 自動で 運ばれる（ともしびを 使わない）。**風の羽 3まいは 1本の 風の道の 上**に あるので、のれば 必ず とれる。島どうしは 行き・帰り 両方 ある。
4. **ふわり**（滑空）：小回りを 大きく（向きの 追従 6倍・最大 4.2）、速さを おさえ（9／上位の 羽 11）、沈みを 0.85倍に。入力を はなすと 減速する。
5. 羽の 拾える 範囲を 3.6m に。目的の 矢印は 風の道の 入り口を さす。ハルの ヒントと 風の試練の 文を 風の道に。

## 記録

- ファイル：lumen.js（新規・talkplus.js の あと）、game.js（ふわり・HOOK.windRide・HOOK.lightRegen）、名前の 置きかえ（がんばり→ともしび）。
