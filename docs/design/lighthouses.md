# ともしびアイランド 灯台ダンジョン設計仕様書

本書は、風灯の島（第1章）の5基の灯台および海の底（第4章）の3基の沈んだ灯台を、単なる「門番との1戦＋点火」から「3つの謎解き・仕掛けを攻略して頂点を目指す攻略ダンジョン」へと昇華させるための仕様書である。
既存の祠システム（shrines.js）のブロック配置・スイッチ・押し箱・上昇気流・光の道の仕組みを流用し、iPhone横画面（タッチ操作）で快適に遊べる設計とする。

---

## 1. ダンジョン構造の基本共通ルール
- **規模**: 灯台周囲 20m×20m、高さ 12m〜16m の立体構造（螺旋スロープ＋踊り場＋内部小部屋）。
- **操作性**: ジャンプ＋よじ登り＋風布滑空を活用。カメラが見失わないよう、壁面は適度に開放窓を設ける。
- **チェックポイント**: 各灯台の1階入口を開けるとワープ/再挑戦ポイントが有効化される。

---

## 2. 風灯の島（第1章）の灯台 5基

### 2.1 第1灯台：野原の灯台（テーマ：光の道とステップ）
- **仕掛け1「導きの飛び石」**: 水路で分断された道を、水面から出入りする「光る足場ブロック」のタイミングに合わせて渡る。
- **仕掛け2「おもしの感圧板」**: 扉を塞ぐ格子を開けるため、近くの「おもしブロック」を押して台座にはめる（押し箱パズル初級）。
- **仕掛け3「灯火の欠片集め」**: 螺旋階段の崩落部を迂回するため、壁面の出っ張りをつたって3箇所の欠片に触れる。

### 2.2 第2灯台：双塔の灯台（テーマ：高低差と滑空）
- **仕掛け1「昇降リフト」**: スイッチを踏むと一定時間上昇する足場に乗り、中間フロアへ登る。
- **仕掛け2「双塔の渡し橋」**: 向かいの塔へ渡るため、歯車ブロックを押して跳ね橋を降ろす。
- **仕掛け3「風布ダイブ」**: 高い方の塔の頂上から飛び降り、風布で滑空してもう一方の塔の火皿があるテラスへ着地する。

### 2.3 第3灯台：岩山の灯台（テーマ：重量と破壊）
- **仕掛け1「転がる巨岩」**: 坂道を転がり落ちてくる丸石ブロックの合間を縫って側壁の退避スペースへ逃げ込みながら登る。
- **仕掛け2「ひび割れた壁」**: 道具のピッケルまたはイワノコの突進で、脆い石ブロック壁を壊して隠し階段を露出させる。
- **仕掛け3「三連重量スイッチ」**: ソラ、ミオ、モンスターが同時に踏む（またはブロックを2個配置して踏む）ことで主扉が開く。

### 2.4 第4灯台：月夜の灯台（テーマ：夜間と鏡の反射）
- **仕掛け1「月光パネル」**: 夜間にのみ起動する太陽光/月光センサー。時間を「夜まで待つ」で切り替えて道を開く。
- **仕掛け2「角度つき反射鏡」**: 3基の鏡ブロックを押して向きを変え、月光を一箇所に集めて結晶を溶かす。
- **仕掛け3「消える灯火の床」**: 踏むと数秒で点滅して消えるガラスブロックの回廊を、立ち止まらずに駆け抜ける。

### 2.5 第5灯台：崖の灯台（テーマ：強風と連続滑空）
- **仕掛け1「吹き出し風穴」**: 一定周期で強い風が吹き出す壁穴。風が止んだ瞬間に走り抜ける。
- **仕掛け2「風向きレバー」**: スイッチを叩くことで風穴の向きが変わり、上昇気流となって上層へ運ばれる。
- **仕掛け3「浮き足場の連鎖」**: 崖外に浮遊する3つの足場を、滑空とジャンプを交互に駆使して点火台へ到達する。

## 3. 海の底（第4章）の沈んだ灯台 3基

### 3.1 藻の灯台（テーマ：水流と浮力）
- **仕掛け1「泡エレベーター」**: 海底の噴気孔から吹き出す巨大泡に乗り、浮力で上層デッキへと浮上する。
- **仕掛け2「絡みつくコンブ」**: 刃物系スキル（または斬撃）で絡みつく海藻ブロックを断ち切り、水車を回転させて水門を開く。
- **仕掛け3「潮流サーフィン」**: 横向きの強い水流ゾーンに飛び込み、障害物を左右にかわしながら灯室へ滑り込む。

### 3.2 甲羅の灯台（テーマ：重厚スイッチとオウム貝）
- **仕掛け1「大甲羅の蓋」**: 水圧で重くなったオウム貝の蓋ブロックを、下からのレバー操作で水流を吹き込ませて持ち上げる。
- **仕掛け2「サンゴの迷路」**: 触れると痺れる毒サンゴを避けながら、狭い海底回廊を進む。
- **仕掛け3「沈没船の舵輪」**: 灯台にめり込んだ沈没船の舵を回して、灯台外周の階段ブロックを正しい位置にドッキングさせる。

### 3.3 雷の灯台（テーマ：電気伝導と避雷針）
- **仕掛け1「クラゲの放電線」**: 帯電したクラゲモンスターや電気ブロックのスパークを、鉄ブロックを並べて端子まで通電させる。
- **仕掛け2「水流スイッチの遮断」**: 漏電して進めない通路を、ブロックで水流をせき止めて漏電を止める。
- **仕掛け3「深海避雷針」**: 最上階の避雷針に雷エネルギーを誘導し、チャージされた電力でメイン灯火を点灯させてボス部屋の防壁を解除する。
