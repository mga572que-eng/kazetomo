# ボスの 間を ダンジョンに・ダンジョンの 中は 一人称

記録：Claude ／ 2026-10-05 ／ 開発者の 指示「敵の ボス的な ところは 必ず ダンジョンに。屋根付きで 中に 入れば 一人称、ギミックも 特殊に」

## しくみ（bossdun.js）
- 番人・ボスの 場所で しらべると「奥へ つづく 扉」→ 入る。中は 屋根の ある 2つの 間：手前の「しかけの 間」と 奥の「番人の 間」。
- しかけを とくと 扉が ひらき、奥の「番人の 封印」で 戦う。戦いの 前後の 話・ほうび・進行フラグは もとの 処理を そのまま 使う（game.js に つなぎ目 HOOK.bossGate／bossDone）。
- 勝つと もとの 場所へ もどって 続き（灯の樹は 灯を ともす、風の祠は 祠に 風が かよう）。負けると いつもどおり 宿へ。
- 部屋は 地方ごとに 1つ（遠くの 空の 上）を 入るたびに 組みなおし、出ると こわす（地方の ブロック数を ふやさない）。描く 上限を こえた ときは 主人公に 近い ブロックを 優先（world.js）。
- 記録：G.bossDun（しかけを といた 場所）。2回目からは 扉が ひらいている。

## 場所と しかけ
| 場所 | ボス | しかけ |
|---|---|---|
| 灯の樹 1つめ〜5つめ（根の間） | ツタカゲ・リク・イワオニ・ウミカゲ・トバリドリ | おもし／はやて／くずれる床／光の かがみ／ひかりの 石盤 |
| 宵の祠の 奥 | ヨミカゲ・よいやみの王 | 灯の 順＋星おぼえ |
| 風の祠 3つ | ツムジカゼ・クモクラゲ・ホシガラス | 風の 流れ／レバー／星座の 床 |
| 星巣の塔の 扉（星晶の間） | 星晶の番人 | 星おぼえ＋はやて |
| 海の さんごの樹 3つ | 藻・甲羅・雷の 番人 | 潮＋レバー／おもし＋はやて／かがみ＋石盤 |
| 深淵の 間 | 深淵の主 | くずれる床＋星座の 床 |
- すでに 屋根の ある 本編ダンジョン（星の遺跡・深淵の宮）は そのまま。星巣の塔の 頂には ガラスの 屋根を 足した。

## 一人称（game.js の camSolve・HOOK.fpv）
- 屋根の ある ダンジョンの 中では 目の 高さの カメラ（主人公は 見えない）。上下の 向きは いつもの ドラッグ。
- 対象：ボスの 間・星の遺跡の 中・深淵の宮の 中・星巣の塔の 中・試練の祠・新しい 3部屋・樹の 中。家の 中は いままでどおり。
- tests/main-dungeon-roofs.mjs の カメラの 検査は「中は 一人称」を 期待する 形に 変更（開発者の 決定による 変更）。
