# 灯台 → 灯の樹（ともしびのき）全面一新 設計書

記録：Claude ／ 2026-10-03 ／ 開発者の決定：「H案（灯の樹）を全面で」

## 1. コンセプト
- 島を守るのは、灯をともす巨大な木「**灯の樹（ともしびのき）**」。
- 根元が入口、**幹の中**を登るのがダンジョン、てっぺんの枝先で**灯の花**がひらくと「ともる」。
- ともすと、その樹のまわりに**季節と花と実り**が戻る（景色が目に見えて変わる）。
- 樹どうしは**根**でつながっていて、ともした樹のあいだを行き来できる（いまの「ワープ」）。
- 題名「ともしびアイランド」・ソラの肩書き「灯守りの家の子」はそのまま合う。

## 3. 見た目
- 外：太い幹＋根（地面に広がる）＋枝の傘＋てっぺんの つぼみ（灯の花）。消えている間は 葉が くすむ。ともると 花が ひらいて 光り、葉が 明るくなる。
- まわり：ともした樹から 半径 約40m に 花が 咲き、木の実の しげみが 増える（地形・道・建物は 動かさない。小物を 足すだけ）。
- 夜：灯の花の 光が 空に のびる（いまの ビームを 流用）。
- 海の底：さんごの 樹（色は 地方の 色）。
