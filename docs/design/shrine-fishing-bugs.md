# 祠の しかけ・調べても 反応しない・釣りが 出る（原因と 再発防止）

記録：Claude ／ 2026-10-06 ／ 開発者の 報告「祠の ギミックが 途中で 機能しなくなる・釣りが どこでも 出る・祠の 調べられる ところで 何も 起きない」

## 原因
1. **釣りの「しらべる」が いちばん 近い あつかい**：釣りの 候補を 主人公の 足もと（距離 0）に 置いていたので、水が 前に あると ほかの しらべる 物（祠の 証・石版・レバー・かがみ）より 必ず 先に えらばれた。条件も「前 2〜4m の 地形が 海」だけで、建物の 上・屋根の 下・ダンジョン（遠い 空の 上に ある 部屋の 下が 海や 雲海）でも 出た。
2. **祠の 中の キノコ**：祠を 建てる とき 木・岩・しげみは どけていたが キノコだけ のこり、天輪の祠では 証の台より キノコが 先に えらばれた。
3. **「処理中」の まま 止まる おそれ**：待ち時間の 処理が、縦向きの 間は 画面の 向きの 知らせ だけを 待っていた。知らせを 取りこぼすと 処理中の まま 止まり、どこを しらべても 反応しなくなる。

## 直し方
- life.js：釣りは「自然の 地面か 海べの 低い 足場」「屋根の 下でない」「一人称の ダンジョン・家・樹の 中・ボスの 間でない」「前の 水まで かべが ない」ときだけ（K.canFish）。候補は 前の 水面（2.4m 先）に 置き、近くの しらべる 物を 優先。
- shrines.js：祠の 中の キノコも どける。game.js：ダンジョンの 中（一人称）や 建物の 上では 木・岩・実・キノコを 候補に しない。
- game.js：待ち時間は 0.25秒ごとに 見なおす。「処理中」なのに 会話・メニュー・戦闘・暗転・演出が どれも ない 状態が 30秒 つづいたら 解除する 安全網。

## 再発防止（npm run test）
- 「釣り：ダンジョン・祠・家・ボスの間・新しい部屋・屋根の下では 出ない／浜べでは 出る」：雲海と 海の 地方の ボスの間・試練の祠 7・新しい 3部屋・家の 中で 8方向 すべて 確認。
- 「試練の祠：7つの しかけを 実際に 解いて 証が とれる」：おもし・灯の順・はやて・築き・力（3連戦）・天輪（輪を くぐる）・星おぼえ を 解き、証の台が 選ばれて 証が 取れる。
