# 本編の 新しい階・新しい謎解き

記録：Claude ／ 2026-10-03 ／ 開発者の指示「本編の新階層・新しい謎解き」

任意の灯の樹の中（lighthouses.js の 4階）とは別物。本編の ダンジョンに 階を 足す。

## 1件目：星の遺跡 2階「星見の間」（mainfloors.js）
- 入り方：遺跡の 北の 外がわの 石段（西の はしから 東へ 12段）→ 踊り場 → 屋根の 上 → 2階の 北の 入口。
- 謎「光の かがみ」：西の かべの 星の 石から 光が 東へ のびる。かがみ 5まい（しらべると 向きが かわる）で 光を 直角に まげ、東の 星の 結晶へ とどける。光の 道は 目に 見えるので、ためしながら とける。こたえは 4まい（5まい目は まよわせ）。星の 石を しらべると 石版の ヒントと「かがみを もとに もどす」。
- とけると 南の ガラスの 扉が きえ、バルコニーの「星見の台」で ほうび（1500G・星のかけら3・夜露のしずく2、1回だけ）。
- 進行は しばらない：迷路・中ボス・祭壇・宝箱6こ・入口の 位置と 第2章の 流れは そのまま。第2章の あとでも（くじらで もどって）遊べる。
- 記録：`G.flags.ruinsStar`（なし＝最初・1＝扉が ひらいた・2＝ほうびずみ）だけ。かがみの 向きは セーブしない（とけたら こたえに そろう）。旧セーブは 記録なし＝最初から。
- 建物は 保護ブロック（プレイヤーの 置いた ブロックの セーブに 入らない）。かがみと 結晶は 見えない かべ（19）で 通りぬけない。
- 地図に ◈（とけたら ✦）、クエスト一覧に 1行（第2章の うわさの あと）。
- 検査：`npm run test 星見`（石段を ふつうの 入力で のぼる・最初は 扉が しまり 光は とどかない・とく前の ほうび拒否・こたえで 扉・ほうび 1回・記録なしで 扉が もどる）。PCの Chromium で 撮影確認。実機未確認。

## 2件目：星巣の塔「星座の間」（mainfloors.js 後半）
- 塔の 中の 階段の 13段目と 同じ 高さに 7×7の 床を 張った（階段・屋上の 祭壇・中ボス・第3章の 流れは そのまま）。階段から そのまま 歩いて 入れる。
- 謎「星座の 床」：床の 星の 石を、星座の 点線で つながる 順に ふむ。はじまりは いちばん 大きく 明るい 星。線の ない 星（3こ）や 順の ちがう 星を ふむと はじめから。ふんだ 星は 金色に。
- とけると 真ん中に 光の 台、ほうび（2500G・料理1・夜露のしずく3、1回だけ）。石版で ヒントと「もとに もどす」。
- 記録：`G.flags.towerStars`（1＝とけた・2＝ほうびずみ）だけ。地図と クエスト一覧は 虹の橋の あと（c3bridge）に 出る。
- 検査：`npm run test 星座`（階段から 床へ 歩いて 上がる・明るい 星から でないと 進まない・線の ない 星と 順ちがいで やりなおし・ほうび 1回）。

## 3件目：深淵の宮 屋上「潮の間」（mainfloors.js 末尾）
- 宮の 西の 外がわの 石段（南から 北へ 17段）→ 屋根 → 屋上の 部屋（内がわ 13×13）。決戦の 扉・宮の 中・第4章の 流れは そのまま。
- 謎「潮の 流れ」：青い 床に のると 矢印の 向きへ 運ばれる（毎秒7m、歩きより 速い）。かべの 戸口の 潮は 一方通行。北東の 真珠の 台へ 行く 道を 見きわめる。とびこえ 対策で、低く とんでいる 間も 運ぶ。部屋の 中は かべを 登れない。
- 道の 確認：盤面を 幅優先探索で 解けることを 確認（25歩）。北の 2つの 戸口は もどされる だけの まよわせ。
- ほうび：3000G・料理2・夜露のしずく3（1回だけ）。記録は `G.flags.palaceTide`（2＝ほうびずみ）だけ。
- ch4.js：決戦の 扉の しらべる 判定に「宮の 床の 高さ 付近（±8）」を 追加（屋上から 決戦が はじまらないように。1行）。
- 検査：`npm run test 潮の間`（石段で のぼる・西むきの 戸口で もどされる・北むきで 運ばれる・とびこえ不可・登れない・屋上から 決戦の 扉が 出ず 下では 出る・ほうび 1回）。
