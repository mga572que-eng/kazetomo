# 建物と灯台の結合

2026-10-02。C1家、C2灯台、C3予算・保存保持の担当を分け、相互レビューで結合した。

## 変更

- C1：既存53棟の軒・棟、入れる家の閉天井・壁・梁・壁灯。入退室のカメラ調整。
- C2：任意の灯台内部8区間に高天井、高窓、太い外柱。既存の3つの間を保ち、扉の先に1mずつ上がる階段と4階ひざらを追加。全体を縦積みの4層へ置換したものではない。

## 確認

家の専用描画検査成功。全地域で20軒の入退室・8区間の灯台再構築、プレイヤー配置ブロック保持が成功。描画ブロック最大は地域0=13739、1=18020、2=7960、3=9763（保護されない検査ブロック1個を含む、見えない19は除外）。上限24000以内。最後の段の修正でブロック数は減少する。

相互レビューと短い歩行検査で、最後の階段にひざらブロックが重なり2m段差になっていたことを検出し、床の印へ変更した。検査を通すために移動速度・段差判定を緩めていない。

最終の灯台描画3位置、通常W入力と120フレーム上限の物理進行による4階到達が成功。29フレームで到達し、入力停止後も目標範囲内。回帰はモジュールとHOOK、家の入退室・検索、祠と灯台の隠し部屋の3件が成功。今回全13件を再実行したとは扱わない。構文・参照・PWA・空白検査も成功。GPUが遅いため、描画確認と既存デバッグのフレーム進行による入力・衝突検査を分ける。後者は実時間の操作感の測定ではない。
