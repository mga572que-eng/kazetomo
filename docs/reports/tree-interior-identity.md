# 灯の樹8本の見分けやすさ

更新: 2026-10-03

## 変更

- 野原：若葉の輪と、太い根
- ふたご：二つの幹を結ぶ枝橋
- いわやま：岩を抱えた根
- つきよ：月明かりを返す鏡の列
- がけ：らせんに舞う風の葉
- 藻のさんご：上から垂れる藻
- 甲羅のさんご：甲羅の節のような横骨
- 雷のさんご：雷を受ける光の柱

目印は歩く通路と既存のしかけの外へ置いた。座標、4階構造、報酬、セーブキー、進行条件、HOOKは変更していない。8本の見た目IDが重ならないことと、各内部に目印があることを自動検査へ追加した。

- 構文・参照・PWA検査
- 8本の構造、屋根、階段、3しかけ、報酬一度だけ、建築量
- 全ブラウザー回帰検査
