## 対応

1. 敵札は画面内の隣接間隔で幅を制限。長い名前は省略。3Dでは対象選択メニューで指している敵・行動中の敵だけ弱点を表示し、領域は予約して上下の揺れを防ぐ。
2. 味方の札も操作欄の上へ収める。
3. 技説明は選択中だけ全文、それ以外は1行。スクロールの案内を付ける。
4. bParty/bBottomは1フレーム1回だけ読む。他の計測も書き込み前にまとめ、style更新後のレイアウト読み取りを除去。倍率1の親要素が固定位置の基準をずらしていたため、3Dの親のscaleをnoneに変更。重さの実測値はない。
5. 通常コマンドは改行しない。横幅に応じた字体で「✦れんけい」を1行にする。
6. 検査画像をtests/outへ保存し、Git対象から外す。実行方法をtests/README.mdに追記。
7. 共通字体の変更は戦闘だけでなく、カジノ・宝箱・設定など従来--pixelを使っていた画面にも及ぶ。PR説明にこの範囲を明記する。
8. 版番号の最終調整はClaudeの統合時に照合。ローカルの今回の版は20261002221500。PR39を統合したとは扱わない。
